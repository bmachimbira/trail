# Trail — Design Context

## Design Context

### Users
A small team / friend group around one self-hoster. Two distinct moments:
- **Sender** (technical, uses the app): drops a file, grabs a link, pastes it into chat.
- **Recipient** (colleague/friend, lands cold on a share page): opens link on any
  device, glances at what it is, downloads. Must trust the page instantly.

Job to be done: move a file from person A to person B with zero ceremony and a
link that quietly expires.

### Brand Personality
Warm, precise, unhurried. The feel of quality stationery and a well-set page —
a tool that respects both the file and the reader. Never corporate-dashboard,
never cyber-toy.

### Aesthetic Direction
**Warm paper minimal.** Cream paper surfaces, warm ink text, one terracotta
accent used sparingly. Editorial serif display type (Fraunces) for voice;
humanist sans (Karla) for UI utility; mono only for genuinely code-like content
(file IDs, links). Hairline rules and list dividers instead of boxed cards.
Light mode only. Subtle paper-grain texture is allowed at whisper opacity.

**Imagery:** the sender's home page carries a WeTransfer-style full-bleed
background — warm-toned AI-generated photographs (cream/terracotta/earth
palette), self-hosted under `public/backgrounds/` and rotated per page load.
They sit behind the UI multiply-blended into the paper at ~60% with a paper
scrim, so they read as printed texture rather than a slideshow. Recipients'
share pages stay pure paper — the image is the sender's daily delight, not
the recipient's concern.

Anti-references: purple-blue gradients, glassmorphism/blur cards, neon-on-dark,
icon-above-every-heading templates, generic drop-shadow rounded rectangles,
sparkline decoration, big-number hero metrics.

### Design Principles
1. **Paper first.** Cream ground, ink marks, generous margins — the page reads
   like something printed with care.
2. **One accent, spent carefully.** Terracotta marks primary actions and key
   moments (the download, the send). Everything else is ink and hairlines.
3. **Typography carries the design.** Serif gives voice and hierarchy; the sans
   stays quiet. No font does the other's job.
4. **Motion decelerates.** Brief ease-out entrances, no bounce; disappear
   instantly under `prefers-reduced-motion`.
5. **Every word earns its place.** Short, warm, human copy ("Sent." not
   "Upload completed successfully").

### Theme
Light only. Palette anchored in OKLCH: paper ~oklch(97% 0.012 85), ink
~oklch(24% 0.02 60), terracotta accent ~oklch(62% 0.17 42).

### Type
- Display: Fraunces (variable, self-hosted via @fontsource-variable)
- Body/UI: Karla (variable, self-hosted)
- Mono: system mono stack — used only for IDs, links, size figures' digits optional
